From this version on, the app updates itself.

- **Updates take care of themselves.** The app checks GitHub once a day and offers each new release with its notes. **agent-grange-viz ▸ Check for Updates…** checks now.
- **This is the last one to download by hand.** Versions 0.1.1 and 0.1.2 cannot see it. Download it from this page once and replace the app you have.
- **An update is checked before it is trusted.** The app verifies each download, and the list of releases itself, against this app's own signing key, and takes neither without it.
- **Closing the window quits the app**, also while an update is on offer.
- **It needs macOS 27** or later on Apple silicon. On an earlier macOS the viewer still runs from source in a terminal; the README says how.
